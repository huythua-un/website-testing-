Cách chạy & tùy biến trên máy của bạn
  1. Khi bấm vào nút Đăng nhập, SWA CLI sẽ chuyển hướng bạn tới trang mock. Bạn có thể tự gõ Username và thêm role admin.
  2. Tập tin cấu hình quyền được đặt tại public/staticwebapp.config.json.
  3. Lệnh khởi chạy nhanh: swa start ./public hoặc dùng file config swa start.
